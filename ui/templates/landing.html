Why Mini Heroku

Everything a developer needs to ship

A complete deployment platform running on a single VM, built from scratch: build pipeline, container orchestration, reverse proxy, add-ons and monitoring.

🚀

Deploy from Git

Clone, build and start any repository with a Dockerfile. Zero-downtime blue/green redeploys built-in.

🔒

HTTPS by default

Caddy + Let's Encrypt issue certificates automatically. Custom domains supported.

🗄

Postgres & Redis add-ons

Provision real databases on an isolated network and attach them — DATABASE_URL is injected for you.

📈

Live metrics & logs

CPU, memory and real-time logs streamed straight to your browser, with release history and rollback.

🔁

Scale with zero code

Spin up replicas for load balancing with a click — Caddy routes traffic across all of them.

🛡

Secure by design

Hashed API tokens with rotation, CSRF protection, rate-limiting and encrypted environment variables.

How it works

From repository to production

1

Connect

Create an account and point Mini Heroku at any public Git repository containing a Dockerfile.

2

Deploy

We build the image in an isolated container with CPU/RAM limits, then start it behind the reverse proxy.

3

Attach add-ons

Provision Postgres or Redis and attach them. Connection strings appear as environment variables.

4

Monitor

Watch live metrics, stream logs, scale replicas and roll back releases — all from the dashboard.
