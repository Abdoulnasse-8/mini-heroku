Lowercase letters, numbers and dashes. This becomes your subdomain.

Any HTTPS git repo containing a Dockerfile. A PORT=8000 app is exposed automatically.

How it works

  1. We clone your repository on the VM.
  2. We build the Docker image and push it to the local registry.
  3. Your app is started in an isolated container with CPU/RAM limits and auto-restart.
  4. Caddy routes <name>.{{ base_domain }} to your container.
  5. Let's Encrypt issues an HTTPS certificate automatically.

Tip: a simple Dockerfile that listens on port 8000 is all you need.
